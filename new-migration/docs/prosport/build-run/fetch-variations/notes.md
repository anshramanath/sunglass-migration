# fetch-variations notes — proSPORT Sunglasses

## Fields kept in slim-variations

| Field | Shape | Notes |
|---|---|---|
| `id` | integer | WP variation post ID |
| `parent_id` | integer | Parent product ID — native from API, verified against fetch key |
| `name` | string | Auto-generated by WC e.g. `"Matte Black x Gloss Tortoise, 4.00"` |
| `status` | string | All `publish` |
| `description` | string | 429/1758 populated |
| `permalink` | string | Canonical variation URL |
| `sku` | string | Variation SKU — all 1758 present and unique |
| `price` | string | Display price — 1757/1758 present |
| `regular_price` | string | 1757/1758 present |
| `sale_price` | string | Present when on sale; reliable on variations (unlike parent products) |
| `on_sale` | boolean | Reliable — every `True` has a real `sale_price` |
| `stock_quantity` | integer | All 1758 have a real quantity (`manage_stock=True` on all) |
| `stock_status` | string | `instock` / `outofstock` — consistent with `stock_quantity` on all variations |
| `weight` | string | 1757/1758 populated |
| `dimensions` | object | `{length, width, height}` — all empty strings. Drop at reshape. |
| `image` | `{src, name}` | Singular object — 1758/1758 have a valid src |
| `attributes` | `[{name, option}]` | Per-variation selected options. 1–2 attributes each. |

## Fields dropped entirely

Always null, always the same constant, or carry no useful signal:

`type` (always `"variation"`), `date_created`, `date_created_gmt`, `date_modified`, `date_modified_gmt`, `global_unique_id` (always `""`), `date_on_sale_from/to` (always null), `purchasable` (derived), `virtual`, `downloadable`, `downloads`, `download_limit`, `download_expiry`, `tax_status`, `tax_class`, `manage_stock` (always `True`), `backorders`, `backorders_allowed`, `backordered`, `low_stock_amount`, `shipping_class`, `shipping_class_id`, `menu_order`, `meta_data`, `_links`

## Gotchas

- **`on_sale` reliable on variations** — opposite of parent products. Every `on_sale=True` variation has a `sale_price`. Safe to use directly.
- **`manage_stock=True` on all variations** — every variation has a real `stock_quantity`. Unlike parent products where most had none.
- **`image` is singular** — not an array. Shape is `{id, src, name, alt, ...}` — slim to `{src, name}`.
- **`attributes` are selected options** — each entry is `{name, option}` (singular option string), not a list of all options like on the parent product.
- **`dimensions` always empty** — same as parent products. Drop at reshape.
- **1 variation with no price** — id=1355 (parent=1208, SKU=`CA25X095MRMIRROR`). Will be flagged at validation.
